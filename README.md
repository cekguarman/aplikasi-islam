# 🕌 Al-Bayan (البيان) - Portal Riset Islam & Studio Khutbah Jumat

Aplikasi cerdas untuk studi Islam komprehensif, pencarian dalil, ayat Al-Qur'an, hadits 9 imam, fiqih 4 mazhab, perbandingan agama, serta generator naskah Khutbah Jum'at dan ceramah terstruktur dengan durasi kustom.

### 2. Studio Generator Khutbah Jum'at & Ceramah
- **Format Pilihan:**
  - **Khutbah Jum'at Lengkap (2 Khutbah):** Memenuhi rukun fiqih (Hamdalah, Syahadatain, Shalawat, Wasiat Taqwa QS. Ali Imran: 102, Bacaan Ayat Al-Qur'an, Inti Khutbah berdalil Hadits, Doa Ampunan Kaum Muslimin & Muslimat, Doa Sapu Jagad, dan Ibadallah).
  - **Ceramah / Majelis Taklim / Kultum:** Salam pembuka, sapaan hormat hadirin, pembahasan tematik, kesimpulan, dan Doa Kafaratul Majelis.
- **Durasi Kustom:** Tombol preset (Kultum 7 Menit, Ceramah Kilat 15 Menit, Khutbah Standar 30 Menit, Kajian Mendalam 40 Menit) serta input menit kustom (misal: 10, 20, 25, 45 menit) yang mengkalibrasi target jumlah kata (~130 kata/menit).
- **10 Pilihan Pembuka (Mukaddimah) Otentik:** Pilihan pembukaan resmi sunnah nabawiyyah, mencakup QS. Al-A'raf: 43, Khutbatul Hajah Sunnah, dan variasi lainnya lengkap dengan harakat, latin, dan terjemahan.

### 3. Opsi Edit & Penyimpanan Riwayat Naskah
- **Mode Edit Langsung:** Pengguna dapat mengedit kembali teks khutbah yang telah digenerate oleh AI sebelum dibawakan atau dicetak.
- **Penyimpanan Naskah Lengkap:** Menyimpan naskah ke riwayat lokal dengan informasi rinci:
  - Judul & Topik
  - Hari (misal: *Jum'at*, *Kamis*)
  - Tanggal, Bulan, Tahun (misal: *22 Oktober 2026*)
  - Jam (misal: *16:20 WIB*)
  - Format, Durasi, dan Jumlah Kata
- **Buka & Unduh Ulang:** Naskah tersimpan dapat dibuka, diedit, atau diunduh ulang kapan saja.

### 4. Format Cetak A4 Rapi & Bersih (Anti-Scrollbar, Anti-Frame)
- **Teks Paragraf Justify:** Seluruh teks narasi diformat rata kanan-kiri (*justify*) agar rapi layaknya buku atau lembaran resmi.
- **Bebas Frame & Scrollbar:** Bersih dari bingkai layar, tombol, maupun elemen web saat dicetak ke kertas A4 atau disimpan ke PDF (`window.print()`).
- **Share Mudah:** Tombol berbagi ke WhatsApp, Salin Naskah, dan Unduh berkas dokumen (`.md`).

### 5. Mode Mimbar / Teleprompter Layar Penuh
- Layar penuh berlatar gelap (*High Contrast Dark Theme*) ramah mata di mimbar.
- Stopwatch / Countdown Timer mundur tersinkronisasi dengan durasi menit yang dipilih (dengan peringatan visual jika waktu tersisa < 2 menit).
- Auto-scroll otomatis dengan pengatur kecepatan (+ / -) dan jeda tombol spasi.

## 🚀 Panduan Menjalankan Secara Lokal

### Prasyarat
- Node.js (v18 ke atas disarankan)
- npm

### Langkah Instalasi
```bash
# 1. Clone repositori
git clone https://github.com/cekguarman/aplikasi-islam.git
cd aplikasi-islam

# 2. Instal dependensi
npm install

# 3. Jalankan server pengembangan
npm run dev

# 4. (Opsional) Jalankan backend lokal dengan Gemini API
npm run server
```

Buka peramban di `http://localhost:5173`.

## ☁️ Panduan Deploy ke Vercel

Proyek ini telah dikonfigurasi penuh dengan `vercel.json` dan serverless functions di folder `/api`.

### Cara Deploy Otomatis (Direkomendasikan via GitHub):
1. Masuk ke akun [Vercel](https://vercel.com/).
2. Klik **Add New Project** &rarr; **Import Git Repository**.
3. Pilih repositori `cekguarman/aplikasi-islam`.
4. Vercel akan secara otomatis mendeteksi:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
5. *(Opsional)* Pada bagian **Environment Variables**, tambahkan:
   - `GEMINI_API_KEY`: *(Kunci API Google Gemini Anda dari Google AI Studio)*
6. Klik **Deploy**. Selesai! Aplikasi Anda akan aktif dalam hitungan detik.
